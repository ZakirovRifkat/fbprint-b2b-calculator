# Словарь

[← Оглавление](README.md)

Одно понятие — одно слово по всему сайту и во всех требованиях. Слова в скобках — как это называется в таблице или в коде.

| Термин | Что значит | Где подробно |
| --- | --- | --- |
| Компания (компания-заказчик, `company`) | юрлицо или бренд клиента, для которого печатают этикетки: «Глобал Фуд», «Студия Вкуса». У каждой свой лист артикулов | [company-switch.md](components/company-switch.md) |
| Площадка | короткая подпись компании: `ГФ`, `СВ`. Колонка B листа артикулов; компанию определяет лист, а не она | [layouts.md](rules/layouts.md) |
| Артикул (`sku`) | код этикетки внутри компании, строка; может быть у двух компаний сразу | [article-search.md](components/article-search.md) |
| Наименование (`name`) | название этикетки, колонка F | — |
| Категория (производственная категория) | набор условий производства: размер, цветность, цены, минимум, кратность, сниженный тираж. Номер — колонка A листа «Категории» | [category-table.md](components/category-table.md) |
| Тираж | сколько штук этикеток заказать | [pricing.md](rules/pricing.md) |
| Минимальный тираж (минимум, `minimumQuantity`) | наименьший тираж по обычной цене | [pricing.md](rules/pricing.md) |
| Кратность (`multiple`) | тираж от минимума должен делиться на это число | [pricing.md](rules/pricing.md) |
| Сниженный тираж (`reducedRun`) | диапазон ниже минимума, который принимается по повышенной цене, только со стандартным сроком | [pricing.md](rules/pricing.md) |
| В роле, ручьёв | сколько этикеток в одном роле и сколько ролей печатается в ширину; из них по умолчанию считается кратность | [category-formulas.md](rules/category-formulas.md) |
| Срок изготовления (срочность, `urgency`) | «Стандартный», «Срочный», «Экстренный»; у каждого своя цена | [urgency-picker.md](components/urgency-picker.md) |
| Цена за штуку | цена категории по сроку или цена сниженного тиража, округлённая до копеек | [pricing.md](rules/pricing.md) |
| Позиция | одна строка заявки: компания, артикул, тираж, срок, цена, сумма | [order-table.md](components/order-table.md) |
| Замечание (`condition`) | пометка позиции: «Сниженный тираж», «Тираж не кратен» | [pricing.md](rules/pricing.md) |
| Заявка (черновик) | позиции, собранные на вкладке «Расчёт» и ещё не отправленные; хранится в браузере | [order-draft.md](rules/order-draft.md) |
| Заявка (отправленная) | заявка с номером `FB-0042 от 09.11.2026`, записана на лист «Заявки» и ушла в Telegram | [order-submission.md](rules/order-submission.md) |
| Статус заявки | «В работе» или «Отгружено» | [order-status-select.md](components/order-status-select.md) |
| Макет | файл с изображением этикетки на Яндекс Диске (JPG, PNG, PDF) | [layouts.md](rules/layouts.md) |
| Папка макетов заявки | папка на Яндекс Диске с макетами всех артикулов заявки, открыта по ссылке | [layout-bundle.md](components/layout-bundle.md) |
| Каталог | компании, категории и артикулы, которые сайт получает от API | [catalog-validation.md](rules/catalog-validation.md) |
| Демо-режим | адрес API в `config.js` пуст: сайт работает на вымышленном каталоге и ничего не отправляет | [api-and-errors.md](rules/api-and-errors.md) |
| Клиент, администратор (`client`, `admin`) | роли по паролю | [access-and-roles.md](rules/access-and-roles.md) |
| Менеджер | сотрудник FB Print, получает заявки в Telegram и ставит статус | — |
