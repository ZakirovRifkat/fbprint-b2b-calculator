# Разбор Excel клиента

[← Оглавление](../README.md)

## Суть

Сайт читает файл `.xlsx` клиента в свободном формате и находит в нём позиции: компанию, артикул, тираж, срок. Потом каждую позицию проверяет по каталогу и по тем же правилам тиража, что калькулятор. Клиенту не нужно переделывать свою таблицу.

Приём файла и ошибки: [excel-import-zone.md](../components/excel-import-zone.md). Показ результата: [import-review-dialog.md](../components/import-review-dialog.md).

## Правила

**Чтение файла**

- **XLSIN-01.** Файл читается целиком в браузере. На сервер он не уходит.
- **XLSIN-02.** Читаются только видимые листы. Скрытые и «очень скрытые» листы пропускаются.
- **XLSIN-03.** Номера строк и столбцов совпадают с Excel: пустые строки и пустые ячейки сохраняют своё место. «Строка 5» в подписи — пятая строка листа в Excel.
- **XLSIN-04.** Значение ячейки берётся так:
  - формула — её сохранённый результат; формула без сохранённого результата — пусто;
  - форматированный текст — все куски текста подряд;
  - гиперссылка — её видимый текст;
  - дата — пусто;
  - пустая ячейка — пусто;
  - число и строка — как есть.
- **XLSIN-05.** Лист, на котором не нашлось ни одной позиции, в результат не попадает.

**Нормализация значений**

- **XLSIN-06.** Сравнение слов (заголовки, названия компаний, срок) идёт в «свободном» виде: строчные буквы, «ё» = «е», все символы, кроме латиницы, кириллицы и цифр, выбрасываются. «Ёлка-1 «Б»» → `елка1б`.
- **XLSIN-07.** Код артикула: текст ячейки без пробелов по краям; хвост «.0», «.00» и т. п. отбрасывается (`1001.0` → `1001`). Внутри кода ничего не меняется, регистр важен.
- **XLSIN-08.** Тираж: число из ячейки или из текста. Из текста убираются все пробелы, включая неразрывные; первая запятая становится точкой. Дробь округляется до целого (`3999,6` → `4000`). Ноль, минус, пусто и не число — тиража нет. Текст с буквами (`4 000 шт`) — тоже не число.
- **XLSIN-09.** Срок: «экстр» в свободном виде — «Экстренный»; иначе «сроч» — «Срочный»; иначе «Стандартный». Пустая ячейка и дата — «Стандартный».

**Строка заголовков**

- **XLSIN-10.** Строка заголовков — строка, где есть ячейка-«код». В свободном виде она равна `код`, `арт` или `кодтовара`, либо начинается с `артикул`. Подходят «Код», «Код:», «Арт.», «Артикул», «Артикул товара», «Код товара». «Код ЕАН» не подходит.
- **XLSIN-11.** Столбец тиража — первый слева столбец строки заголовков, кроме столбца кода, в заголовке которого есть `тираж`, `заказ`, `колич`, `колво` или `шт` и нет `цен`, `стоим`, `сумм`. «Цена за шт» и «Сумма заказа» не берутся.
- **XLSIN-12.** Столбец срока — первый слева столбец, кроме столбца кода, в заголовке которого есть `срок` или `срочн`. Он необязателен: без него у всех строк срок «Стандартный».
- **XLSIN-13.** Компания блока — первая ячейка строки заголовков, которая в свободном виде совпадает с названием компании из каталога целиком. «ГЛОБАЛ-ФУД» совпадает с «Глобал Фуд», «Глобал Фуд ООО» — нет.
- **XLSIN-14.** Строка заголовков задаёт столбцы и компанию для всех строк ниже, до следующей строки заголовков. Так в одном листе бывает несколько блоков разных компаний.
- **XLSIN-15.** Если в строке заголовков нет столбца тиража, все строки под ней пропускаются до следующей строки заголовков. Угадывание без заголовков (XLSIN-17) в этом блоке не работает.
- **XLSIN-16.** Сама строка заголовков позицией не считается.

**Строки без заголовков**

- **XLSIN-17.** Строки выше первой строки заголовков (или все строки, если заголовков нет) разбираются по одной:
  - код — первая заполненная ячейка строки;
  - тираж — первая заполненная ячейка правее, где есть тираж по XLSIN-08;
  - срок — первая заполненная ячейка правее кода, где есть «сроч», «экстр» или «станд» (регистр не важен);
  - компания из файла не задана.
- **XLSIN-18.** Строка без тиража правее кода пропускается.

**Пропуск строк**

- **XLSIN-19.** Строка пропускается, если в коде нет ни одной цифры («Итого», подписи, «Заявка на март»).
- **XLSIN-20.** Строка пропускается, если тиража нет (XLSIN-08).
- **XLSIN-21.** Пропущенные строки нигде не показываются и не считаются.

**Подпись строки**

- **XLSIN-22.** Подпись — «строка {номер}». Если позиции нашлись больше чем на одном листе, подпись — «лист «{название листа}», строка {номер}».

**Компания строки**

- **XLSIN-23.** Компания строки из файла: компания блока (XLSIN-13). Если в строке заголовков компании нет — компания, чьё название совпадает с названием листа (сравнение как в XLSIN-13). Если и её нет — компания из файла не задана.
- **XLSIN-24.** Если компания из файла задана, артикул ищется только у неё. Нет — статус «Нет в каталоге».
- **XLSIN-25.** Если компания из файла не задана, берётся компания, выбранная в [шаге 1](../components/company-switch.md). Артикул ищется у неё.
- **XLSIN-26.** Если в случае XLSIN-25 у выбранной компании такого кода нет, а среди всех компаний он есть ровно у одной, строка получает эту компанию и пометку «Компания определена по артикулу». Если код есть у двух и больше компаний или ни у одной — «Нет в каталоге».
- **XLSIN-27.** Артикул ищется по точному совпадению кода (XLSIN-07) с кодом в каталоге.

**Проверка строки**

- **XLSIN-28.** Статус строки определяется по порядку, первое совпавшее правило:
  1. артикул не найден — «Нет в каталоге»;
  2. та же компания и тот же код уже были выше в файле — «Повтор»;
  3. артикул уже есть в черновике заявки — «Уже в заявке»;
  4. иначе — по правилам тиража ([pricing.md](pricing.md)): «Меньше минимума», «Сниженный тираж», «Не кратен» или «Подходит».
- **XLSIN-29.** «Повтор» — второе и следующие вхождения пары «компания + код». Строки «Нет в каталоге» повторами не бывают. Повторы пересчитываются после удаления и возврата строк: если удалили первую, первой становится следующая такая же.
- **XLSIN-30.** Если тираж ниже минимального тиража категории, строка считается со сроком «Стандартный», какой бы срок ни был в файле. Если строку можно добавить, она помечается, что срок сброшен ([import-review-dialog.md](../components/import-review-dialog.md), IMPREV-14).
- **XLSIN-31.** Добавить можно строки «Подходит», «Сниженный тираж» и «Не кратен». Остальные пропускаются.
- **XLSIN-32.** Рекомендованный тираж:
  - «Не кратен» — ближайший больший кратный;
  - «Меньше минимума» — начало сниженного тиража, если тираж ниже него; иначе минимальный тираж, приведённый к кратности;
  - «Сниженный тираж» — минимальный тираж, приведённый к кратности.
  Формулы: [pricing.md](pricing.md).
- **XLSIN-33.** Массовое исправление («Исправить тиражи») касается только «Не кратен» и «Меньше минимума» с рекомендацией. «Сниженный тираж» — допустимый заказ, поэтому на минимальный он переходит только по кнопке в строке.

## Примеры

Каталог из тестов (`tests/import.test.js`, демо-каталог): компании «Демо-компания А» (`demo_a`) и «Демо-компания Б» (`demo_b`); `1001`, `1002`, `1003` — у А, `2001`, `2002` — у Б; выбрана компания А.

| Вход | Результат |
| --- | --- |
| Ячейка: формула `A1*2` с результатом 4000 | 4000 |
| Ячейка: форматированный текст «10» + «01» | `1001` |
| Ячейка: ссылка с текстом «Салат» | «Салат» |
| Ячейка: дата | пусто |
| Код `1001` (число), « 1001.0 » | `1001` |
| Тираж `4000`, «4 000», «4 000» с неразрывным пробелом | 4000 |
| Тираж «3999,6» | 4000 |
| Тираж −3, «много», пусто | тиража нет, строка пропускается |
| Срок «Срочный» / «ЭКСТРЕННО» / «обычный» / пусто | Срочный / Экстренный / Стандартный / Стандартный |
| Компания в заголовке «демо компания а», «ДЕМО-КОМПАНИЯ Б» | А, Б |
| Компания в заголовке «Другая» | не задана |
| Строка без заголовков `['', '1001', 'Салат', 4000, 'срочно']` | код — столбец B, тираж — столбец D, срок — столбец E |
| Строка без заголовков `['Итого']` | пропускается |
| Лист: «Заявка на март» / «Код · Демо-компания Б · Тираж, шт · Цена · Срок» / «2001 · Сэндвич · 4000 · 1 · срочный» / «Итого · · 4000» / пустая / «=2002 · Каша · ' 6 000'» | две позиции компании Б: `2001` × 4000, Срочный, «строка 3»; `2002` × 6000, Стандартный, «строка 6» |
| Лист без заголовков: `1001 · 4000` / `1002 · много` / `1003 · 5000 · экстренный` | `1001` × 4000, Стандартный, «строка 1»; `1003` × 5000, Экстренный, «строка 3»; компания — выбранная |
| Заголовки «Артикул · Цена за шт · Количество», строка `1001 · 1,5 · 4000` | тираж 4000: столбец цены не берётся |
| Заголовки «Код · Название», строка `1001 · Салат` | позиций нет: нет столбца тиража |
| Строки без компании: `1001`, `2001`, `1001`, `9999` | `1001` — А; `2001` — Б с пометкой «Компания определена по артикулу»; второй `1001` — «Повтор»; `9999` — «Нет в каталоге» |
| Строка `2001` с компанией А из файла | «Нет в каталоге»: у другой компании не ищется |
| `1001` × 4000 Срочный | «Подходит», цена 1,50 ₽, срок не сброшен |
| `1002` при `1002` уже в заявке | «Уже в заявке» |
| `1002` × 3000 Срочный | «Сниженный тираж», срок «Стандартный», «От 6 000 шт. — 0,50 ₽ за штуку.», в массовое исправление не входит |
| `1003` × 7000 | «Не кратен», рекомендация 7 500, «Кратность 2 500 шт.», входит в массовое исправление |
| `1001` × 500 | «Меньше минимума», рекомендация 1 000, входит в массовое исправление |

## При переносе

> [!note] При переносе
> По [плану](../../docs/platform-plan.md) разбор файла (XLSIN-01…XLSIN-27) остаётся на фронтенде. Проверка строк (XLSIN-28…XLSIN-32) может идти через `POST /quotes`: сервер считает статус, цену и рекомендацию по текущему прайсу. Правила проверки должны совпасть с калькулятором и с сервером.

## Вопросы

> [!warning] Расхождение
> Заголовок со словом «Заказчик» подходит под столбец тиража (`заказ`). Если такой столбец стоит левее «Тираж», тираж будет браться из него, и строки пропадут. Вероятно, ошибка.

> [!warning] Расхождение
> Без заголовков тиражом считается первое число правее кода. Если правее кода стоит цена («1,5»), она станет тиражом 2.

> [!question] Вопрос
> Код, сохранённый в Excel числом, теряет ведущие нули (`00123` → `123`) и не найдётся в каталоге. Нужно ли сравнивать коды без ведущих нулей?

> [!question] Вопрос
> Тираж «4 000 шт» не читается (XLSIN-08), и строка молча пропадает. Нужно ли отбрасывать слова у числа?

> [!question] Вопрос
> Код артикула сравнивается с учётом регистра и пробелов внутри (XLSIN-27). Для кодов с буквами («A-12» и «а-12») это даст «Нет в каталоге». Так и задумано?
