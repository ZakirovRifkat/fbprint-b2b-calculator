# Формат Excel заявки

[← Оглавление](../README.md)

## Суть

Какой файл `.xlsx` собирает сайт из черновика заявки. Один и тот же файл клиент скачивает кнопкой «Скачать Excel» и сайт прикладывает к отправленной заявке для менеджера.

## Правила

### Библиотека

- **XLSOUT-01.** Файл собирает библиотека ExcelJS 4.4.0 из `assets/vendor/exceljs.min.js` (около 950 КБ). Она загружается не со страницей, а при первой сборке файла: по «Скачать Excel» или при отправке заявки. Дальше берётся уже загруженная.
- **XLSOUT-02.** Библиотека не загрузилась — ошибка «Не удалось подготовить файл Excel: нет связи с сервером». Следующая попытка грузит её заново.

### Состав книги

- **XLSOUT-03.** По листу на каждую компанию из черновика, в порядке первого появления компании. На листе — позиции этой компании в порядке добавления. Фильтры, сортировка и страницы таблицы на файл не влияют.
- **XLSOUT-04.** Имя листа — название компании. Символы `[ ] : * ? / \` заменяются пробелом, длина обрезается до 31 символа (ограничения Excel).
- **XLSOUT-05.** Столбцы:

| Столбец | Заголовок | Ширина | Значение |
| --- | --- | --- | --- |
| A | «Срок» | 14 | «Стандартный», «Срочный» или «Экстренный» |
| B | «Артикул» | 11 | артикул, как в каталоге |
| C | «Название» | 60 | наименование |
| D | «Тираж» | 12 | число |
| E | «Цена за шт.» | 17 | число |
| F | «Итого» | 16 | формула `ROUND(Dn*En,2)` |
| G | «Размер» | 14 | размер этикетки или пусто; столбец скрыт, его можно показать в Excel |

- **XLSOUT-06.** Строка 1 — заголовки. Позиции — со строки 2.
- **XLSOUT-07.** В ячейке «Итого» позиции — формула `ROUND(D{n}*E{n},2)` и готовое значение (сумма позиции из черновика). Файл показывает суммы и без пересчёта формул.
- **XLSOUT-08.** После позиций — строка итога: в столбце E текст «Итого», в столбце F формула `SUM(F2:F{последняя строка позиций})` и готовое значение — сумма позиций листа до копеек. Строка жирная, «Итого» прижато вправо.
- **XLSOUT-09.** В файле нет номера заявки, даты, итога по всем компаниям и замечаний («Сниженный тираж», «Тираж не кратен»).

### Оформление

- **XLSOUT-10.** У всех ячеек столбцов A–G во всех строках (заголовок, позиции, итог) — тонкая рамка цвета `#9A97AD`.
- **XLSOUT-11.** Выравнивание по верху; перенос текста только в столбце C.
- **XLSOUT-12.** Заголовки: жирный шрифт, заливка `#EDEBF3`, по центру по обеим осям, с переносом.
- **XLSOUT-13.** Форматы: D — `#,##0`; E и F — `#,##0.00 "₽"`.
- **XLSOUT-14.** Первая строка закреплена.
- **XLSOUT-15.** Печать: A4, альбомная, в ширину одной страницы, по высоте — сколько нужно.

### Скачивание

- **XLSOUT-16.** Перед сборкой — проверки: заявка не пуста, в ней нет позиций, которые нельзя заказать ([order-footer.md](../components/order-footer.md), OFOOT-09, 10).
- **XLSOUT-17.** Имя файла — `fbprint-order-{ГГГГ-ММ-ДД}.xlsx` по дате на устройстве клиента, например `fbprint-order-2026-11-21.xlsx`. Тип — `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.
- **XLSOUT-18.** Скачивание работает без сервера: в демо-режиме и без связи, если библиотека уже загружена.

### Файл к заявке

- **XLSOUT-19.** При отправке сайт собирает книгу заново по тем же правилам и кладёт её в поле `file` запроса в base64 ([order-submission.md](order-submission.md), OSEND-09). Не собралась — заявка уходит без файла.
- **XLSOUT-20.** Сервер принимает файл, только если: это непустая строка не длиннее 700 000 символов; после декодирования не больше 500 000 байт; первые два байта — `PK` (zip, как у настоящего .xlsx). Иначе или при ошибке декодирования файл отбрасывается, заявка уходит без него.
- **XLSOUT-21.** Имя файла задаёт сервер: `{номер заявки}.xlsx`, например `FB-0042 от 09.11.2026.xlsx`. Подпись в Telegram — «Excel заявки {номер}».
- **XLSOUT-22.** Файл уходит следом за сообщением и только в чаты, которые приняли сообщение ([telegram.md](telegram.md)). Если Telegram файл не принял, заявка всё равно считается отправленной.

## Примеры

| Вход | Результат |
| --- | --- |
| 3 позиции «Глобал Фуд», 2 позиции «Студия Вкуса» | два листа: «Глобал Фуд» (строки 2–4, итог в строке 5), «Студия Вкуса» (строки 2–3, итог в строке 4) |
| компания «A/B: тест» | лист «A B  тест» |
| позиция 5 600 шт. × 1,13 ₽ | D 5 600, E 1,13 ₽, F `ROUND(D2*E2,2)` = 6 328,00 ₽ |

## При переносе

> [!note] При переносе
> По [плану](../../docs/platform-plan.md) «Скачать Excel» остаётся на клиенте (ExcelJS, ленивая загрузка). Файл для менеджера собирает сервер (`excelize`) из сохранённых позиций: ему можно верить, поле `file` в запросе больше не нужно. Появляется `GET /api/v1/orders/{id}/excel`. Формат файла сервера должен совпадать с этим описанием.

## Вопросы

> [!warning] Расхождение
> README («Возможности») называет столбцы «Срочность, Артикул, Наименование, Тираж, Стоимость за шт., Итого». В коде заголовки другие: «Срок», «Артикул», «Название», «Тираж», «Цена за шт.», «Итого».

> [!warning] Расхождение
> Файл к заявке собирает браузер клиента, поэтому его можно подделать. Верить можно только тексту сообщения в Telegram, где сервер помечает расхождения цен (README, «Защита от спама»).

> [!question] Вопрос
> Нужно ли в файле замечание позиции («Сниженный тираж», «Тираж не кратен») и номер заявки? Сейчас их нет, хотя на сервере замечание пишется в «Позиции заявок».
