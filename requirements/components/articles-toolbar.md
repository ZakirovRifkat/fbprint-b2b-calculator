# Фильтры и поиск артикулов

[← Оглавление](../README.md)

## Назначение

Сужает список карточек на вкладке «Артикулы»: по компании, только артикулы без макета, по тексту. Показывает, сколько файлов в папке макетов и когда список обновлён.

## Где используется

- [Артикулы](../pages/articles.md) — над карточками

## Состав

1. Переключатель компании «Все», «Глобал Фуд», «Студия Вкуса» со счётчиками — [ui-segmented-filter.md](ui-segmented-filter.md).
2. Кнопка-переключатель «Без макета» со счётчиком — [ui-segmented-filter.md](ui-segmented-filter.md).
3. Поле поиска — [ui-search-field.md](ui-search-field.md).
4. Строка статуса: синхронизация и «Показано N из M».
5. Текст пустого результата — [ui-empty-state.md](ui-empty-state.md).

## Поведение

- **ATBAR-01.** Фильтры (пункты 1–3) скрыты, пока список ни разу не загрузился. Строка статуса видна всегда.
- **ATBAR-02.** Кнопки компаний строятся из списка `companies` ответа `articleLayouts`. Первая — «Все».
- **ATBAR-03.** Число на кнопке компании — сколько всего артикулов у компании. На «Все» — сколько артикулов всего. Другие фильтры и поиск эти числа не меняют.
- **ATBAR-04.** Выбранная компания отмечена `aria-pressed="true"`, остальные — `false`. Выбрана может быть одна. По умолчанию — «Все».
- **ATBAR-05.** Клик по компании сразу перерисовывает карточки. Фокус остаётся на нажатой кнопке.
- **ATBAR-06.** «Без макета» — переключатель: клик включает, повторный клик выключает. Состояние — в `aria-pressed`.
- **ATBAR-07.** Включённый «Без макета» оставляет только карточки без макета. Без макета — нет файла или есть проблема `missing`, `conflict` или `notFound`. Причина видна в карточке: [article-card.md](article-card.md).
- **ATBAR-08.** Число на «Без макета» — сколько артикулов без макета у выбранной компании («Все» — у обеих). Поиск это число не меняет.
- **ATBAR-09.** Поиск идёт по каждому вводу символа, без кнопки и без задержки.
- **ATBAR-10.** Поиск смотрит в артикул, наименование и имя найденного файла макета. Значение колонки «Макет», которого нет на Диске, в поиск не входит.
- **ATBAR-11.** Регистр не важен, «ё» равно «е», пробелы по краям не важны.
- **ATBAR-12.** Запрос делится на слова по пробелам. Карточка подходит, если каждое слово есть где-то в артикуле, наименовании или имени файла. Пример: «щи свежей» найдёт «Щи из свежей капусты», а «лисичек студ» не найдёт ничего: название компании в поиск не входит.
- **ATBAR-13.** Слово ищется как часть текста: «1505» найдёт 15053 у обеих компаний.
- **ATBAR-14.** Три фильтра действуют вместе: компания, затем «Без макета», затем поиск.
- **ATBAR-15.** Фильтры и запрос сохраняются, пока открыта страница: при уходе с вкладки и возврате, после обновления списка.
- **ATBAR-16.** Строка синхронизации во время первой загрузки пустая: загрузку показывают заготовки карточек ([индикаторы загрузки](ui-spinner.md), SPIN-08). Во время повторной загрузки остаётся прежний текст. После загрузки — «Файлов в папке макетов: {N}. Обновлено в {ЧЧ:ММ}». Время — местное время браузера, когда пришёл ответ.
- **ATBAR-17.** Если фильтры показывают не все артикулы, к строке статуса добавляется « · Показано {N} {артикул|артикула|артикулов} из {M}». Если показаны все — добавки нет. Склонение — по [formatting.md](../rules/formatting.md).
- **ATBAR-18.** Если ни одна карточка не подошла и включён «Без макета» без поиска — текст «У всех артикулов есть макет.» В остальных случаях — «Ничего не нашлось. Проверьте артикул или название.»
- **ATBAR-19.** Состояние фильтров влияет на окно просмотра: оно листает только видимые карточки с макетом ([layout-viewer.md](layout-viewer.md)), а новый артикул по умолчанию получает выбранную компанию ([article-dialog.md](article-dialog.md)).

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Скрыт | список ещё не загружен | только строка статуса |
| Обычный | список загружен | все фильтры, строка «Файлов в папке макетов…» |
| Обновление | список грузится заново | фильтры доступны, строка «Загружаем…» |
| Пусто | фильтр не оставил карточек | текст пустого результата под строкой статуса |

## Тексты

| Где | Текст |
| --- | --- |
| Кнопка «все компании» | «Все» |
| Переключатель | «Без макета» + число |
| Подсказка в поле поиска | «Артикул, название или файл» |
| Название поля для чтения с экрана | «Найти артикул» |
| Название группы компаний | «Компания» |
| Готово | «Файлов в папке макетов: 400. Обновлено в 14:05» |
| Счёт показанных | « · Показано 12 артикулов из 400» |
| Пусто, «Без макета» | «У всех артикулов есть макет.» |
| Пусто, иначе | «Ничего не нашлось. Проверьте артикул или название.» |

## Клавиатура и доступность

- **ATBAR-20.** Кнопки компаний и «Без макета» — обычные кнопки: Tab и Enter/пробел. Стрелками они не переключаются.
- **ATBAR-21.** Группа компаний — `role="group"` с названием «Компания».
- **ATBAR-22.** Строка статуса — `aria-live="polite"`: изменение числа найденных читается вслух.

## Узкий экран

До 720 px фильтры стоят в один столбец: компании, «Без макета», поиск во всю ширину. Шире — в одну строку с переносом, поле поиска растягивается.

## Вопросы

> [!question] Вопрос
> Если на листах вообще нет артикулов, сайт пишет «Ничего не нашлось. Проверьте артикул или название.» Нужен ли отдельный текст для пустого листа?

> [!question] Вопрос
> Строка «Файлов в папке макетов» считает все файлы, включая вложенные папки до 4 уровней и не только JPG, PNG, PDF. Так и задумано?
