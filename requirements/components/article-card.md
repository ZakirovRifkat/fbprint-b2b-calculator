# Карточка артикула

[← Оглавление](../README.md)

## Назначение

Одна строка листа артикулов: превью макета, артикул, компания, наименование, файл макета или причина, почему его нет, и действия с артикулом.

## Где используется

- [Артикулы](../pages/articles.md) — сетка карточек

## Состав

Сверху вниз (на узком экране превью слева):

1. Превью макета — кнопка, открывающая [layout-viewer.md](layout-viewer.md), или плашка «Нет макета».
2. Шапка: артикул крупно, рядом «{Компания} · {размер}».
3. Наименование.
4. Ссылка на файл в Яндекс Диске или текст проблемы.
5. «Строка {N} на листе «{Компания}»».
6. Действия: «Изменить», «Загрузить макет» или «Заменить макет», корзина «Удалить артикул».

## Поведение

**Макет и превью**

- **ACARD-01.** Карточка «с макетом» — если у артикула есть путь к файлу и нет проблемы. Иначе — «без макета». У карточки атрибут `data-state` = `ok` или `problem`.
- **ACARD-02.** У карточки с макетом превью — кнопка с подписью «Посмотреть макет {имя файла}». Клик открывает [layout-viewer.md](layout-viewer.md) на этом макете.
- **ACARD-03.** У карточки без макета на месте превью — плашка «Нет макета» в предупреждающем цвете. Она не нажимается.
- **ACARD-04.** Превью грузится лениво: запрос уходит, когда карточка оказывается ближе 400 px к видимой части экрана по вертикали. Если браузер не умеет следить за прокруткой (`IntersectionObserver`), превью всех карточек запрашиваются сразу.
- **ACARD-05.** Превью запрашиваются пачками: до 12 путей в одном запросе `layoutPreviews` (размер `M`, около 300 px), не больше 2 запросов одновременно. Остальные ждут в очереди.
- **ACARD-06.** Готовое превью хранится в памяти страницы по пути файла и не запрашивается снова до обновления списка. Карточки с одним файлом (общий артикул двух компаний) показывают одно превью. Повторы пути в очереди схлопываются.
- **ACARD-07.** Пока превью не пришло, на его месте крутится спиннер.
- **ACARD-08.** Превью пришло — показывается картинка целиком, вписанная в рамку 4:3, без обрезки.
- **ACARD-09.** Превью пустое (у файла нет превью, путь вне папки макетов) или запрос не удался — текст «Превью нет». Повторно не запрашивается до обновления списка. Кнопка просмотра остаётся.
- **ACARD-10.** Ошибка превью не показывается пользователем: только запись в консоль. Карточка и ссылка на файл работают.

**Текст карточки**

- **ACARD-11.** Шапка: артикул; рядом название компании и размер через « · ». Пустой размер не выводится.
- **ACARD-12.** Наименование — заголовок карточки. Пустое — «Без названия».
- **ACARD-13.** У карточки с макетом — ссылка с именем файла. Она открывает файл в веб-интерфейсе Яндекс Диска в новой вкладке. Для чтения с экрана добавлено « (откроется в новой вкладке)».
- **ACARD-14.** Ссылка ведёт в папку файла с открытым просмотром этого файла. Открывается только у того, кто вошёл в аккаунт Яндекса с макетами. Файлы не публикуются. Как строится адрес — [layouts.md](../rules/layouts.md).
- **ACARD-15.** У карточки без макета вместо ссылки — текст проблемы в предупреждающем цвете:
  - `missing` — «На Диске нет файла с этим артикулом»;
  - `conflict` — «На Диске несколько файлов: {имена через запятую}. Впишите нужный в колонку «Макет»»;
  - `notFound` — «В колонке «Макет» указан «{значение колонки}», но такого файла на Диске нет».
- **ACARD-16.** Внизу мелко — «Строка {N} на листе «{Компания}»». N — номер строки в таблице.

> [!warning] Расхождение
> В тексте «Строка 158 на листе «Глобал Фуд»» стоит название компании. Настоящее имя листа другое: «Список_артикулов_ГлобалФуд». Так же в подтверждении удаления.

**Действия**

- **ACARD-17.** «Изменить» открывает [article-dialog.md](article-dialog.md) с данными этого артикула. Подпись для чтения с экрана — «Изменить артикул {артикул}».
- **ACARD-18.** Кнопка макета называется «Заменить макет», если у артикула есть файл или проблема `conflict` или `notFound`. Если файла нет (`missing`) — «Загрузить макет». Подпись для чтения с экрана — «{Заменить|Загрузить} макет артикула {артикул}». Что происходит дальше — [layout-upload.md](layout-upload.md).
- **ACARD-19.** Корзина справа — удаление. Подсказка при наведении «Удалить артикул», подпись для чтения с экрана — «Удалить артикул {артикул}».
- **ACARD-20.** Клик по корзине открывает подтверждение ([ui-confirm-dialog.md](ui-confirm-dialog.md)): заголовок «Удалить артикул {артикул}?», текст «Строка {N} исчезнет с листа «{Компания}», строки ниже сдвинутся вверх. Отменить нельзя. Макет на Яндекс Диске останется.», кнопка «Удалить».
- **ACARD-21.** «Отмена», Esc или клик мимо окна — ничего не удаляется.
- **ACARD-22.** После подтверждения корзина выключается до ответа. Запрос `deleteArticle` несёт компанию, номер строки и артикул.
- **ACARD-23.** Успех — уведомление «Артикул {артикул} удалён», затем заново грузятся список артикулов и каталог калькулятора ([articles.md](../pages/articles.md)).
- **ACARD-24.** Ошибка — корзина снова включается, уведомление не исчезает само ([ui-toast.md](ui-toast.md)). Текст: сообщение сервера для кодов `ARTICLE_*`, `*_FAILED`, `ADMIN_REQUIRED`; иначе «Артикул не удалён: {причина}».
- **ACARD-25.** Сервер удаляет строку, только если в ней тот же артикул (без учёта регистра, «ё» = «е», пробелы по краям). Иначе `ARTICLE_CHANGED`: «Строку артикула уже изменили или сдвинули в таблице. Обновите страницу и попробуйте снова». Ничего не удаляется.
- **ACARD-26.** Строка удаляется целиком, строки ниже сдвигаются вверх. Файл макета на Диске остаётся.
- **ACARD-27.** Другие ошибки удаления: неизвестная компания — `ARTICLE_INVALID` «Неизвестная компания»; нет листа — `ARTICLE_SAVE_FAILED` «Нет листа «{имя листа}»»; таблица занята дольше 30 с — `ARTICLE_DELETE_FAILED` «Таблица занята другим запросом. Попробуйте через минуту»; сбой записи — `ARTICLE_DELETE_FAILED` «Не удалось удалить артикул: {причина}».

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Заготовка | список грузится впервые | серая карточка: спиннер в превью, три серые полоски; не нажимается, скрыта от чтения с экрана |
| С макетом, превью грузится | превью ещё не пришло | спиннер, ссылка на файл |
| С макетом, превью есть | превью пришло | картинка, ссылка на файл |
| С макетом, превью нет | превью пустое или ошибка | «Превью нет», ссылка на файл, просмотр открывается |
| Без макета | `missing`, `conflict`, `notFound` | «Нет макета», текст проблемы |
| Удаляется | удаление подтверждено | корзина выключена |
| Загружается макет | см. [layout-upload.md](layout-upload.md) | кнопка макета «Загружаем…», выключена |

## Клавиатура и доступность

- **ACARD-28.** Превью с макетом, ссылка, «Изменить», кнопка макета и корзина доступны по Tab. Плашка «Нет макета» в порядок Tab не входит.
- **ACARD-29.** Картинка превью — без замещающего текста: подпись несёт кнопка.

## Узкий экран

Шире 720 px карточки идут сеткой, каждая не уже 250 px; превью сверху, 4:3. До 720 px — одна колонка; карточка делится на две части: превью слева шириной 104 px, текст справа.
