# Зона «Заявка из Excel»

[← Оглавление](../README.md)

## Назначение

Принимает файл Excel клиента со списком позиций. Файл перетаскивают на зону или выбирают кнопкой. После разбора открывается [окно «Проверка заявки»](import-review-dialog.md).

## Где используется

- [Расчёт](../pages/calculator.md) — в левой колонке, под [предупреждением об ошибке каталога](catalog-alert.md) и над шагом 1 «Компания-заказчик».

Зона стоит над шагами намеренно. В одном файле бывают позиции разных компаний. Компанию сайт берёт из таблицы, а не из шага 1 (комментарий в `index.html`). Как определяется компания: [excel-import.md](../rules/excel-import.md).

## Состав

1. Иконка: стрелка загрузки; после загрузки файла — галочка в круге.
2. Текст `#import-drop-text`: «Заявка из Excel» и подсказка «: перетащите файл сюда».
3. Кнопка «Выбрать файл» ([кнопки](ui-button.md), вид `bulk-button`).
4. Скрытое поле выбора файла `#import-file`.

Ход загрузки и ошибки показывает [уведомление](ui-toast.md).

## Поведение

- **IMPZONE-01.** Нажатие «Выбрать файл» открывает системное окно выбора файла. Выбрать можно один файл.
- **IMPZONE-02.** В окне выбора стоит фильтр: `.xlsx` и тип `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`. Фильтр можно обойти в системном окне, поэтому сайт проверяет файл ещё раз (IMPZONE-09).
- **IMPZONE-03.** После выбора поле файла очищается. Тот же файл можно выбрать снова, и он разберётся заново.
- **IMPZONE-04.** Пока над зоной тащат файлы, у зоны состояние «перетаскивание»: розовая рамка и фон, иконка розовая. Перетаскивание текста или ссылки состояние не включает и не обрабатывается.
- **IMPZONE-05.** Состояние «перетаскивание» не мигает при движении над текстом и кнопкой внутри зоны. Оно снимается, только когда курсор ушёл из зоны целиком или файл бросили.
- **IMPZONE-06.** Файл, брошенный на зону, отправляется на разбор. Если бросили несколько файлов, берётся только первый, остальные молча отбрасываются.
- **IMPZONE-07.** Файл, брошенный мимо зоны в любом месте страницы, браузер не открывает. Сайт ничего с ним не делает и ничего не сообщает.
- **IMPZONE-08.** Если каталог ещё не загружен (в нём нет ни одного артикула), файл не разбирается. Уведомление: «Каталог ещё загружается. Выберите файл через минуту.»
- **IMPZONE-09.** Если имя файла не кончается на `.xlsx` (регистр не важен), файл не разбирается. Уведомление: «Нужен файл Excel в формате .xlsx.» Так отклоняются `.xls`, `.csv`, `.ods` и прочие.
- **IMPZONE-10.** Проверки идут в порядке: каталог (IMPZONE-08), затем расширение (IMPZONE-09).
- **IMPZONE-11.** Перед разбором показывается уведомление «Читаем файл…». Оно обычное: само скрывается через 5 секунд. Других признаков загрузки нет: зона и кнопка остаются доступны, файл можно бросить ещё раз.
- **IMPZONE-12.** Для чтения файла сайт при первом обращении подгружает библиотеку ExcelJS (`assets/vendor/exceljs.min.js`). Та же библиотека нужна для «Скачать Excel». Если она не загрузилась: «Не удалось подготовить файл Excel: нет связи с сервером». Следующая попытка снова пробует её загрузить.
- **IMPZONE-13.** Если файл не читается как `.xlsx` (повреждён или это `.xls`, переименованный в `.xlsx`): «Не удалось прочитать файл. Сохраните таблицу в формате .xlsx и попробуйте снова.»
- **IMPZONE-14.** Если в файле не нашлось ни одной строки с артикулом и тиражом: «В файле не нашлось строк с артикулом и тиражом. Нужны столбцы «Код» или «Артикул» и «Тираж» или «Количество».» Как ищутся строки: [excel-import.md](../rules/excel-import.md).
- **IMPZONE-15.** Все сообщения об ошибке (IMPZONE-08, 09, 12, 13, 14) — уведомления, которые висят, пока их не закроют. После ошибки вид зоны не меняется.
- **IMPZONE-16.** Если строки нашлись, зона переходит в состояние «файл загружен» (IMPZONE-17), и открывается [окно «Проверка заявки»](import-review-dialog.md).
- **IMPZONE-17.** В состоянии «файл загружен» вместо стрелки — зелёная галочка, рамка сплошная зелёная, фон зелёный. Текст: «**Файл загружен:** {имя файла} · {N} строка / строки / строк». N — сколько строк с артикулом и тиражом нашлось в файле, до проверки по каталогу: сюда входят и строки «Нет в каталоге», и «Повтор». Кнопка называется «Выбрать другой файл».
- **IMPZONE-18.** Состояние «файл загружен» держится до перезагрузки страницы. Закрытие окна проверки, добавление позиций и очистка заявки его не сбрасывают.
- **IMPZONE-19.** В состоянии «файл загружен» зона принимает новый файл так же. При перетаскивании рамка снова розовая пунктирная. Новый файл полностью заменяет строки прошлого в окне проверки.
- **IMPZONE-20.** Зона работает и в демо-режиме: строки проверяются по демо-каталогу.

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Исходное | после загрузки страницы | пунктирная сиреневая рамка, стрелка загрузки, «Заявка из Excel: перетащите файл сюда», кнопка «Выбрать файл» |
| Перетаскивание | над зоной тащат файл | рамка и фон розовые, иконка розовая |
| Чтение файла | файл принят, идёт разбор | вид зоны прежний; уведомление «Читаем файл…» |
| Файл загружен | разбор нашёл строки | галочка, сплошная зелёная рамка, «Файл загружен: {имя} · {N} строк», кнопка «Выбрать другой файл» |
| Файл загружен + перетаскивание | над загруженной зоной тащат файл | пунктирная розовая рамка, розовый фон |
| Ошибка | любая из IMPZONE-08, 09, 12, 13, 14 | вид зоны прежний; уведомление с причиной висит до закрытия |

## Клавиатура и доступность

- **IMPZONE-21.** Перетаскивание без мыши недоступно; с клавиатуры файл выбирают кнопкой «Выбрать файл» (Tab, Enter или пробел).
- **IMPZONE-22.** Текст зоны — живая область (`aria-live="polite"`): смена на «Файл загружен: …» зачитывается программой чтения экрана.
- **IMPZONE-23.** Иконки скрыты от программ чтения экрана (`aria-hidden`).

## Узкий экран

- **IMPZONE-24.** На сенсорных устройствах (`pointer: coarse`) подсказка «: перетащите файл сюда» скрыта. Видно только «Заявка из Excel» и кнопку.
- **IMPZONE-25.** До 720 px ширины кнопка стоит отдельной строкой под текстом, прижата влево. Отступы блока меньше.
- **IMPZONE-26.** До 720 px ширины зона переезжает вниз: после шага 3, под расчётом цены. Причина из комментария в `style.css`: на телефоне заявку из Excel собирают редко.
- **IMPZONE-27.** В состоянии «файл загружен» длинное имя файла переносится в любом месте и не раздвигает зону.

## Вопросы

> [!question] Вопрос
> IMPZONE-08 срабатывает и тогда, когда каталог не загрузился с ошибкой или пуст. Текст «Каталог ещё загружается» в этих случаях неверен. Нужен отдельный текст?

> [!question] Вопрос
> Во время чтения файла зона не блокируется (IMPZONE-11). Два файла подряд разбираются параллельно, в окне останется тот, что дочитался последним. Блокировать зону на время чтения?

> [!warning] Расхождение
> `README.md` пишет, что ExcelJS загружается «только при первом нажатии «Скачать Excel»». В коде её загружает и разбор файла клиента (IMPZONE-12).

> [!note] При переносе
> По [плану](../../docs/platform-plan.md) разбор файла остаётся на фронтенде (`features/excel-import`). Зона, её состояния и тексты переносятся без изменений.
