# Загрузка макета

[← Оглавление](../README.md)

## Назначение

Положить файл макета артикула на Яндекс Диск прямо с сайта. Здесь — сторона браузера: выбор файла, проверки, подтверждение замены, ожидание, итог. Имя файла на Диске, запись в колонку «Макет» и корзина для старых файлов — в [layouts.md](../rules/layouts.md).

## Где используется

- [Карточка артикула](article-card.md) — кнопка «Загрузить макет» или «Заменить макет»

## Состав

1. Кнопка в карточке: «Загрузить макет» или «Заменить макет».
2. Скрытое поле выбора файла, одно на страницу.
3. Подтверждение замены — [ui-confirm-dialog.md](ui-confirm-dialog.md).
4. Уведомление об итоге — [ui-toast.md](ui-toast.md).

## Поведение

- **LUPLOAD-01.** Кнопка называется «Заменить макет», если у артикула есть файл или проблема `conflict` или `notFound`; при `missing` — «Загрузить макет».
- **LUPLOAD-02.** Клик открывает системное окно выбора файла. Окно предлагает `.jpg`, `.jpeg`, `.png`, `.pdf`. Поле очищается перед каждым открытием: тот же файл можно выбрать снова.
- **LUPLOAD-03.** Закрыли окно выбора без файла — ничего не происходит.
- **LUPLOAD-04.** Выбранный файл проверяется в браузере, по порядку:
  - тип — JPG, PNG или PDF по MIME-типу, а если тип не распознан — по расширению (`jpg`, `jpeg`, `png`, `pdf`, регистр не важен); иначе «Макет должен быть JPG, PNG или PDF»;
  - размер 0 байт — «Файл пустой»;
  - больше 20 МБ (20 × 1024 × 1024 байт) — «Файл больше 20 МБ».
- **LUPLOAD-05.** Файл не прошёл проверку — уведомление с причиной, которое не исчезает само. Запрос не отправляется.
- **LUPLOAD-06.** Если кнопка «Заменить макет», после проверки файла открывается подтверждение: заголовок «Заменить макет {артикул}?», текст «Новый файл станет макетом артикула {артикул} у всех компаний. Старый ({имена}) уйдёт в корзину Яндекс Диска, оттуда его можно восстановить.», кнопка «Заменить».
- **LUPLOAD-07.** В скобках — имя текущего файла; при `conflict` и `notFound` — имена из `candidates` через запятую. Если имён нет, вторая фраза не выводится.
- **LUPLOAD-08.** «Отмена», Esc или клик мимо окна — загрузка не начинается.
- **LUPLOAD-09.** При «Загрузить макет» подтверждения нет: загрузка начинается сразу после проверки.
- **LUPLOAD-10.** Во время загрузки кнопка этой карточки выключена и называется «Загружаем…». Процента и полосы нет. Остальные кнопки страницы доступны.
- **LUPLOAD-11.** Браузер читает файл целиком и отправляет его в `uploadLayout` строкой base64 в JSON вместе с компанией, номером строки, артикулом, исходным именем файла и типом (`image/jpeg`, `image/png`, `application/pdf`). Тайм-аут — 180 с.
- **LUPLOAD-12.** Успех — уведомление «Макет {имя на Диске} загружен на Яндекс Диск.», затем список артикулов загружается заново. Каталог калькулятора не перезагружается.
- **LUPLOAD-13.** Ошибка — уведомление, которое не исчезает само; карточка перерисовывается, кнопка снова доступна. Текст: сообщение сервера для кодов `LAYOUT_UPLOAD_*`, `ARTICLE_*`, `*_FAILED`, `ADMIN_REQUIRED`; иначе «Макет не загружен: {причина}».
- **LUPLOAD-14.** Сервер повторяет проверки браузера и отвечает `LAYOUT_UPLOAD_INVALID`: «Макет должен быть JPG, PNG или PDF» (тип не из трёх), «Файл не прочитался. Выберите его ещё раз» (base64 не разобрался), «Файл пустой», «Файл больше 20 МБ».
- **LUPLOAD-15.** Если в строке уже не тот артикул — `ARTICLE_CHANGED` «Строку артикула уже изменили или сдвинули в таблице. Обновите страницу и попробуйте снова». Файл на Диск не кладётся.
- **LUPLOAD-16.** Нет токена Диска — `LAYOUTS_NOT_CONFIGURED`, текст «Макет не загружен: Сборка макетов не настроена: нет токена Яндекс Диска». Диск отказал — `LAYOUT_UPLOAD_FAILED` «Не удалось загрузить макет: {причина}»; если Диск не принял токен, причина — «Яндекс Диск не принимает токен — макеты не собираются. Замените YANDEX_DISK_TOKEN в свойствах скрипта.».
- **LUPLOAD-17.** Новое имя заменяет макет артикула у обеих компаний: [layouts.md](../rules/layouts.md).

> [!warning] Расхождение
> При `notFound` подтверждение обещает, что «старый» файл уйдёт в корзину, но такого файла на Диске нет: в скобках — значение колонки «Макет».

> [!warning] Расхождение
> Если браузер не смог прочитать файл, уведомление будет «Макет не загружен: Сервер ответил с ошибкой» — хотя сервер не участвовал.

> [!warning] Расхождение
> Если во время загрузки список перерисуется (ввели текст в поиск, сменили фильтр), кнопка снова станет «Заменить макет» и доступной. Можно запустить вторую загрузку того же артикула.

> [!warning] Расхождение
> Ответ сервера содержит `trashed` — какие файлы ушли в корзину. Сайт его не показывает. В `API_CONTRACT.md` у `LAYOUTS_NOT_CONFIGURED` и `ARTICLE_CHANGED` не указан `uploadLayout`, у `LAYOUT_UPLOAD_INVALID` нет случая «Файл не прочитался».

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Ожидание | обычно | «Загрузить макет» или «Заменить макет» |
| Подтверждение | замена, файл прошёл проверку | окно «Заменить макет …?» |
| Загрузка | файл отправлен | «Загружаем…», кнопка выключена |
| Готово | сервер принял | уведомление, список обновляется |
| Ошибка | проверка, сеть, сервер | уведомление без автоскрытия, кнопка доступна |

## Тексты

| Где | Текст |
| --- | --- |
| Кнопка | «Загрузить макет» / «Заменить макет» / «Загружаем…» |
| Подтверждение | «Заменить макет 19747?» / «Новый файл станет макетом артикула 19747 у всех компаний. Старый (ГФ_19747_80x120.jpg) уйдёт в корзину Яндекс Диска, оттуда его можно восстановить.» / «Заменить» |
| Не тот тип | «Макет должен быть JPG, PNG или PDF» |
| Пустой | «Файл пустой» |
| Большой | «Файл больше 20 МБ» |
| Нет файла | «Файл не выбран» (в коде есть; при обычной работе не показывается — без файла загрузка не начинается) |
| Успех | «Макет ГФ_19747_80x120.jpg загружен на Яндекс Диск.» |
| Ошибка сети | «Макет не загружен: Сервер не ответил вовремя» |

## Клавиатура и доступность

- **LUPLOAD-18.** Скрытое поле файла не входит в порядок Tab и скрыто от чтения с экрана. Выбор файла — только кнопкой в карточке.
