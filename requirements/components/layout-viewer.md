# Просмотр макета крупно

[← Оглавление](../README.md)

## Назначение

Показать макет артикула крупно и пролистать макеты текущего списка, не открывая Яндекс Диск.

## Где используется

- [Артикулы](../pages/articles.md) — открывается кликом по превью в [карточке артикула](article-card.md)

## Состав

Модальное окно почти во весь экран ([ui-dialog.md](ui-dialog.md)):

1. Верхняя полоса: «{артикул} · {Компания}» мелко, под ним имя файла крупно; ссылка «Открыть в Яндекс Диске»; кнопка закрытия.
2. Сцена: стрелка «назад» слева, картинка (или спиннер, или текст) в центре, стрелка «вперёд» справа.
3. Счётчик «{N} из {M}» внизу.

## Поведение

- **LVIEW-01.** Окно открывается кликом по превью карточки с макетом. У карточек без макета превью не нажимается.
- **LVIEW-02.** Листаются только карточки с макетом, которые сейчас видны по фильтрам: компания, «Без макета», поиск ([articles-toolbar.md](articles-toolbar.md)). Порядок — как в сетке. Окно открывается на макете нажатой карточки.
- **LVIEW-03.** Набор для листания запоминается при открытии. Если список за это время обновился, окно листает прежний набор до закрытия.
- **LVIEW-04.** В верхней полосе: «{артикул} · {название компании}» и имя файла. Ссылка «Открыть в Яндекс Диске» ведёт на этот файл, открывается в новой вкладке; для чтения с экрана добавлено « (откроется в новой вкладке)».
- **LVIEW-05.** Сразу показывается превью карточки (размер `M`), если оно уже загружено. Одновременно запрашивается крупное превью `XL` (около 800 px) одним путём в `layoutPreviews`. Пришло — заменяет маленькое.
- **LVIEW-06.** Пока крупного нет и маленького тоже нет — в центре спиннер.
- **LVIEW-07.** Крупное пришло пустым или с ошибкой, а маленького нет — текст «Превью нет. Откройте макет в Яндекс Диске.» Если маленькое есть — остаётся маленькое.
- **LVIEW-08.** Крупное превью каждого файла запрашивается один раз за сессию страницы, вместе с неудачей. Обновление списка его не сбрасывает; сбрасывает только смена роли.
- **LVIEW-09.** Ответ на крупное превью, пришедший после перехода к другому макету, экран не меняет — только запоминается.
- **LVIEW-10.** Картинка вписывается в сцену целиком, без обрезки. Замещающий текст — «Макет {имя файла}».
- **LVIEW-11.** Стрелки «Предыдущий макет» и «Следующий макет» листают по кругу: после последнего — первый, перед первым — последний.
- **LVIEW-12.** Если в наборе один макет, стрелок нет и счётчика нет.
- **LVIEW-13.** Счётчик — «{номер} из {всего}», например «3 из 41».
- **LVIEW-14.** Соседние макеты заранее не грузятся: крупное превью запрашивается при переходе на макет.
- **LVIEW-15.** Окно закрывается кнопкой закрытия, клавишей Esc, кликом по затемнению вокруг окна или по пустому месту сцены вокруг картинки. Клик по картинке, стрелкам, спиннеру или тексту окно не закрывает.
- **LVIEW-16.** При смене роли на `client` открытое окно закрывается.

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Ждёт | нет ни маленького, ни крупного превью, запрос идёт | спиннер |
| Маленькое | есть превью карточки, крупное ещё грузится | картинка размера `M` |
| Крупное | крупное пришло | картинка `XL` |
| Нет превью | крупное пустое или ошибка, маленького нет | «Превью нет. Откройте макет в Яндекс Диске.» |
| Один макет | в наборе один файл | без стрелок и счётчика |

## Клавиатура и доступность

- **LVIEW-17.** Стрелка влево — предыдущий макет, стрелка вправо — следующий. Работает, пока фокус внутри окна.
- **LVIEW-18.** Esc закрывает окно.
- **LVIEW-19.** Название окна для чтения с экрана — имя файла. Счётчик — `aria-live="polite"`: номер читается при листании.

## Узкий экран

Окно занимает экран с отступом 16 px, не больше 1100 × 900 px. До 720 px верхняя полоса переносится: имя файла и кнопка закрытия в первой строке, ссылка «Открыть в Яндекс Диске» — под ними; отступы сцены меньше.

## Зависит от

- [layouts.md](../rules/layouts.md) — превью на сервере: размеры `M` и `XL`, кэш, путь только внутри папки макетов
- [articles-toolbar.md](articles-toolbar.md) — какой набор листается

> [!note] При переносе
> Крупное превью — картинка по адресу `GET /admin/layouts/{id}/preview?size=XL` с кэшем браузера, вместо data-URL в JSON ([план](../../docs/platform-plan.md)).
