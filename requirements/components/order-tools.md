# Поиск, фильтры и сортировка заявки

[← Оглавление](../README.md)

## Назначение

Помогает найти нужные позиции в большой заявке: поиск по артикулу и названию, фильтры по компании, сроку и замечанию, сортировка. Меняет только то, что видно в таблице, сам черновик не трогает.

## Где используется

- [Панель заявки](order-panel.md) — между шапкой и [таблицей](order-table.md).

## Состав

Одной строкой с переносом:

1. Поле поиска с иконкой лупы (см. [ui-search-field.md](ui-search-field.md)).
2. Список «Компания».
3. Список «Срок».
4. Список «Тираж».
5. Список «Сортировка» — только на узком экране.
6. Кнопка-ссылка «Сбросить».

Внутри таблицы, когда фильтры не оставили строк: текст и кнопка «Сбросить фильтры».

## Поведение

**Когда виден**

- **OTOOLS-01.** Блок скрыт, если в заявке меньше 6 позиций и ни один фильтр не активен. С 6 позиций он виден всегда.
- **OTOOLS-02.** Если фильтр активен, блок остаётся видимым и при меньшем числе позиций: иначе фильтр нельзя было бы снять.

**Поиск**

- **OTOOLS-03.** Поиск ищет подстроку в строке «{артикул} {наименование}» позиции. Регистр и «ё»/«е» не различаются ([formatting.md](../rules/formatting.md)).
- **OTOOLS-04.** Фильтр применяется на каждый ввод символа, без кнопки и без задержки.
- **OTOOLS-05.** Пробелы в начале и в конце запроса не обрезаются. Запрос из одних пробелов считается активным фильтром.

**Фильтры**

- **OTOOLS-06.** «Компания»: «Все компании» и по пункту на каждую компанию, которая есть в заявке, в порядке первого появления. Список пересобирается при каждом изменении заявки.
- **OTOOLS-07.** Список «Компания» скрыт, если в заявке меньше двух компаний.
- **OTOOLS-08.** Если выбранной компании больше нет в заявке (её позиции удалили), фильтр по компании сбрасывается на «Все компании».
- **OTOOLS-09.** «Срок»: «Любой срок», «Стандартный», «Срочный», «Экстренный». Показывает позиции с этим сроком.
- **OTOOLS-10.** «Тираж»: «Любой тираж», «С замечаниями», «Сниженный тираж», «Не кратен». «С замечаниями» — позиции со сниженным тиражом или некратным тиражом. Остальные пункты — только позиции с этим замечанием.
- **OTOOLS-11.** Позиции, которые нельзя заказать («Нет в каталоге», «Тираж мал»), фильтр «С замечаниями» не находит, если их замечание не «сниженный» или «не кратен».
- **OTOOLS-12.** Все фильтры и поиск действуют вместе (логическое «и»).
- **OTOOLS-13.** Список с выбранным значением (не «Все…» / «Любой…») выделяется: тёмная рамка, фон, жирный шрифт.
- **OTOOLS-14.** Любое изменение поиска или фильтра открывает первую страницу ([order-pager.md](order-pager.md)).

**Сброс**

- **OTOOLS-15.** «Сбросить» видна, только когда активен поиск или хотя бы один фильтр.
- **OTOOLS-16.** «Сбросить» и «Сбросить фильтры» очищают поле поиска и ставят все три списка на первый пункт, открывают первую страницу. Сортировку они не сбрасывают.
- **OTOOLS-17.** Если фильтры не оставили ни одной строки (а заявка не пуста), под заголовками таблицы — «Под фильтры ничего не подходит.» и кнопка «Сбросить фильтры».
- **OTOOLS-18.** Фильтры сбрасываются сами, когда в заявку добавляют позицию из калькулятора или из Excel, и после успешной отправки. Добавленная позиция должна быть видна (см. [order-pager.md](order-pager.md), OPAGER-09).

**Сортировка**

- **OTOOLS-19.** По умолчанию строки идут в порядке добавления.
- **OTOOLS-20.** Сортировка общая для заголовков таблицы и списка «Сортировка»: это одно состояние. Заголовки — на широком экране ([order-table.md](order-table.md), OTABLE-21…23), список — на узком.
- **OTOOLS-21.** Пункты списка «Сортировка»: «В порядке добавления», «По артикулу» (по возрастанию), «По названию» (по возрастанию), «Сначала большие тиражи», «Сначала дорогие» (по сумме, по убыванию), «Сначала дешёвые» (по сумме, по возрастанию).
- **OTOOLS-22.** Выбор пункта открывает первую страницу.
- **OTOOLS-23.** Список показывает текущую сортировку, если для неё есть пункт. Сортировки по сроку, по цене за штуку и в обратном направлении для артикула, названия и тиража есть только в заголовках. Для них список оставляет прежнее значение.
- **OTOOLS-24.** «По артикулу» сравнивает строку «{компания} {артикул}», где артикул дополнен нулями слева до 12 знаков. Сравнение по-русски, числа внутри строк — как числа. Итог: сначала по компании, внутри — по числовому значению артикула (2 раньше 10).
- **OTOOLS-25.** «По названию» — сравнение по-русски с учётом чисел. Тираж, цена за штуку и сумма — как числа. Срок — по порядку «Стандартный» → «Срочный» → «Экстренный».
- **OTOOLS-26.** Сортировка устойчивая: при равных значениях строки остаются в порядке добавления.
- **OTOOLS-27.** Сортировка не сохраняется: после перезагрузки страницы — порядок добавления. Фильтры тоже не сохраняются.

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Скрыт | меньше 6 позиций, фильтров нет | ничего |
| Обычный | 6 и больше позиций | поле поиска и списки; «Сбросить» скрыта |
| Фильтр активен | любое поле не пустое | выделенный список, «Сбросить» |
| Ничего не найдено | фильтры не оставили строк | в таблице — текст и «Сбросить фильтры»; [страницы](order-pager.md) скрыты |

| Список сроков | «Любой срок», «Стандартный», «Срочный», «Экстренный» |

## Клавиатура и доступность

- **OTOOLS-28.** Подписи для диктора: поле — «Найти в заявке по артикулу или названию»; списки — «Компания», «Срок», «Тираж», «Сортировка». Видимых подписей у списков нет, первый пункт списка служит подписью.
- **OTOOLS-29.** Поле поиска — `type="search"`, автозаполнение выключено. Иконка лупы скрыта от диктора.
- **OTOOLS-30.** Число найденных строк диктору не объявляется.

## Узкий экран

До 720 px:

- появляется список «Сортировка» на всю ширину строки; заголовки таблицы скрыты, поэтому сортировка — только через него;
- остальные списки — по два в строке;
- поле и списки высотой 44 px.

## Вопросы

> [!question] Вопрос
> На узком экране список «Сортировка» не умеет «по сроку» и «по цене за штуку», а на широком нет списка. Если начать сортировку заголовком и сузить окно, список показывает старое значение. Нужно ли выровнять набор вариантов?

> [!question] Вопрос
> Позиции, которые нельзя заказать («Нет в каталоге», «Тираж мал»), никаким фильтром не выделить. Нужен ли пункт для них?
