# Шаг 2: поиск артикула

[← Оглавление](../README.md)

## Назначение

Поле поиска с выпадающим списком. Клиент находит артикул выбранной компании по номеру или части названия и выбирает его для расчёта.

## Где используется

- [Расчёт](../pages/calculator.md) — шаг 2, над карточкой выбранного артикула.

## Состав

1. Номер шага «2», заголовок «Артикул», пояснение «Номер артикула или часть названия этикетки.»
2. Подпись поля «Поиск по каталогу».
3. Поле поиска с иконкой лупы слева (`type="search"`, без автозаполнения браузера), подсказка внутри «Например, 10165 или борщ». Базовый вид поля — [ui-search-field.md](ui-search-field.md).
4. Выпадающий список под полем, поверх содержимого страницы. Строка варианта: артикул (жирно, цифры одной ширины), наименование, справа мелко — размер этикетки или «Уже в заявке».
5. В списке вместо вариантов — строка «ничего не найдено», а под вариантами — строка о том, что показаны не все.

## Поведение

**Что ищется**

- **ASRCH-01.** Ищутся только артикулы компании, выбранной в шаге 1 ([company-switch.md](company-switch.md)).
- **ASRCH-02.** Пробелы в начале и конце запроса отбрасываются. Пробелы внутри запроса остаются: «10 165» не найдёт «10165».
- **ASRCH-03.** Артикул подходит, если запрос входит как подстрока в номер артикула или в наименование. Начало строки не обязательно: «165» найдёт «10165».
- **ASRCH-04.** Регистр не важен (сравнение по правилам русского языка). «Ё» и «е» не различаются ни в запросе, ни в названии: «копчёности» найдёт «КОПЧЕНОСТИ» и наоборот. Общее правило «е/ё» — [formatting.md](../rules/formatting.md).
- **ASRCH-05.** Порядок вариантов — порядок артикулов в каталоге (порядок строк листа). Точное совпадение номера наверх не поднимается.
- **ASRCH-06.** Артикулы без категории в каталог не попадают ([catalog-validation.md](../rules/catalog-validation.md)), поэтому в поиске их нет.

**Список вариантов**

- **ASRCH-07.** Показывается не больше 6 вариантов (`searchLimit` в `js/pricing.js`).
- **ASRCH-08.** Если подходящих больше 6, под вариантами строка: при непустом запросе — «Показаны {6} из {всего}. Уточните номер или название.», при пустом — «Показаны {6} из {всего}. Начните вводить номер или название.»
- **ASRCH-09.** Если ничего не подошло — строка «Ничего не найдено. Проверьте номер или название.» и ни одного варианта.
- **ASRCH-10.** Справа в строке варианта — размер этикетки из категории артикула, например «80 × 120 мм».
- **ASRCH-11.** Артикул, который уже есть в заявке (та же компания и тот же номер), показан в списке, но выключен, и справа вместо размера написано «Уже в заявке». Выбрать его нельзя: один артикул — одна позиция.
- **ASRCH-12.** Выключенные варианты занимают место в лимите 6 и учитываются в «Показаны … из …».
- **ASRCH-13.** Если список открыт и заявка меняется (позицию добавили, удалили, заявку очистили, пришли изменения из другой вкладки), список перерисовывается: пометки «Уже в заявке» обновляются сразу.

**Когда список открыт**

- **ASRCH-14.** Список открывается и перерисовывается при каждом вводе, при получении полем фокуса и при нажатии на поле.
- **ASRCH-15.** При пустом запросе список виден, только пока фокус в поле. Тогда он показывает первые 6 артикулов компании и подсказку «Начните вводить…», если их больше.
- **ASRCH-16.** Список закрывается при нажатии мышью (или касании) в любом месте страницы вне блока поиска (поле, подпись, список).
- **ASRCH-17.** Список закрывается после выбора варианта.
- **ASRCH-18.** После новой загрузки каталога список перерисовывается по текущему тексту поля; если поле пусто и не в фокусе — закрывается.

**Выбор**

- **ASRCH-19.** Нажатие на вариант выбирает артикул: поле поиска очищается, список закрывается, появляется [карточка артикула](selected-product.md), шаг 3 включается, в поле тиража ставится минимальный тираж ([quantity-control.md](quantity-control.md)), фокус переходит в поле тиража.
- **ASRCH-20.** Если при выборе артикул уже в заявке (на случай, если выключенную строку всё же нажали), выбор не происходит и показывается уведомление «Этот артикул уже в заявке, тираж меняется там.»
- **ASRCH-21.** Выбор другого артикула, когда один уже выбран, заменяет выбранный. Поле поиска при выбранном артикуле остаётся доступным.
- **ASRCH-22.** Поле поиска выключено, если в каталоге нет компаний ([catalog-alert.md](catalog-alert.md)).

## Состояния

| Состояние | Когда | Что видно и что доступно |
| --- | --- | --- |
| Выключено | каталог пуст | поле серое, ввод недоступен |
| Закрыто | нет фокуса и запрос пуст, или нажали вне блока, или выбрали вариант | только поле |
| Варианты | есть совпадения | до 6 строк, при необходимости строка «Показаны …» |
| Пусто | совпадений нет | «Ничего не найдено. Проверьте номер или название.» |

## Клавиатура и доступность

- **ASRCH-23.** `Ctrl+K` или `⌘K` в любом месте страницы ставит фокус в поле поиска (стандартное действие браузера отменяется). Фокус открывает список. На других вкладках сайта поле скрыто, и сочетание ничего не делает.
- **ASRCH-24.** Поле связано со списком: `aria-controls="search-results"`, `aria-expanded` — `"true"`, когда список открыт, `"false"`, когда закрыт.
- **ASRCH-25.** Список — `role="listbox"`, каждый вариант — кнопка с `role="option"`. Строка «Ничего не найдено…» — `role="status"`.
- **ASRCH-26.** Переход по вариантам — клавишей `Tab`: варианты — обычные кнопки, выбор — `Enter` или пробелом. Выключенные варианты в обход по `Tab` не попадают. Наведённый и сфокусированный вариант подсвечивается одинаково.
- **ASRCH-27.** Стрелки `↑`/`↓` по списку не ходят, `Esc` список не закрывает. Браузер по `Esc` очищает поле поиска; после этого список показывает первые артикулы компании.
- **ASRCH-28.** Уход фокуса с поля клавишей `Tab` список не закрывает: он закрывается только нажатием вне блока поиска или выбором.

## Узкий экран

- **ASRCH-29.** До 720 px в строке варианта две колонки: артикул и наименование. Правая колонка с размером и с пометкой «Уже в заявке» скрыта; выключенный вариант отличается только бледным видом.

> [!warning] Расхождение
> Разметка объявляет `role="listbox"` и `role="option"`, но поведение списка этим ролям не соответствует: нет `aria-selected`, нет `aria-activedescendant`, нет движения стрелками, `Esc` не закрывает список. README обещает «клавиатурную навигацию» — по факту только `Tab`.

> [!note] При переносе
> Поиск остаётся на фронте: каталог приходит целиком ([план](../../docs/platform-plan.md)). Сделать список настоящим комбобоксом: стрелки, `Enter`, `Esc`, закрытие при уходе фокуса.
