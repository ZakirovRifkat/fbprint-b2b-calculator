# B2B-калькулятор FB Print

Статический фронтенд для расчёта стоимости печати этикеток и подготовки заявки из нескольких позиций.

## Запуск

Сборка и установка зависимостей не нужны. Откройте каталог проекта любым статическим HTTP-сервером, например на `http://127.0.0.1:4173/`.

Основные файлы:

- `index.html` — разметка;
- `style.css` — адаптивные стили;
- `app.js` — загрузка, проверка каталога, расчёт и заявка;
- `config.js` — адрес API и тайм-аут;
- `API_CONTRACT.md` — зафиксированная схема JSON и соответствие колонкам Google Sheets;
- `apps-script/Code.gs` — Apps Script, который только читает таблицу и отдаёт каталог;
- `apps-script/appsscript.json` — манифест Apps Script с доступом к таблицам только на чтение;
- `assets/vendor/xlsx.mini.min.js` — SheetJS Community Edition 0.20.3 с `cdn.sheetjs.com`, лицензия Apache 2.0 в `xlsx.LICENSE.txt`. Пакет `xlsx` из npm устарел (0.18.5), поэтому библиотека взята с официального CDN и хранится в проекте.

## Публикация Apps Script

1. Откройте таблицу «ФБ-Принт_заказ этикеток_ГлобалФуд_СтудияВкуса» → «Расширения» → «Apps Script».
2. Замените содержимое `Code.gs` текстом из `apps-script/Code.gs`.
3. В «Настройках проекта» включите «Показывать файл манифеста appsscript.json» и замените его содержимое текстом из `apps-script/appsscript.json`. Манифест даёт два права: `spreadsheets.readonly` — таблица только на чтение, скрипт физически не может её изменить; `script.external_request` — запросы к Telegram.
4. Выберите функцию `test` и нажмите «Выполнить». Google попросит разрешения «Просмотр таблиц Google» и «Подключение к внешней службе». В журнале появится число категорий и артикулов.
5. «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение». «Выполнять от имени»: «Я». «У кого есть доступ»: «Все».
6. Скопируйте URL, который заканчивается на `/exec`, и проверьте его в браузере с параметром `?action=catalog`. Должен открыться JSON.
7. Вставьте URL в `config.js`:

```js
window.FBPRINT_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/DEPLOYMENT_ID/exec',
  requestTimeoutMs: 10000
};
```

Правки в самой таблице не требуют повторной публикации: скрипт читает листы при каждом запросе. После изменения `Code.gs` откройте «Управление развертываниями», отредактируйте текущее развертывание и выберите «Новая версия» — так URL не изменится.

Доступ «Все» означает, что каталог с ценами может получить любой, у кого есть URL. Те же данные и так видит каждый посетитель калькулятора.

## Отправка заявки в Telegram

Кнопка «Отправить менеджеру» шлёт заявку POST-запросом в тот же Apps Script, а он пересылает её в Telegram. Токен бота хранится только в свойствах скрипта и на сайт не попадает.

1. В Telegram откройте @BotFather → `/newbot` и получите токен.
2. Apps Script → «Настройки проекта» → «Свойства скрипта» → добавьте `TELEGRAM_BOT_TOKEN` с токеном.
3. Менеджер пишет боту любое сообщение. Для группы — добавьте бота в группу и напишите в ней.
4. Запустите в редакторе функцию `findChatId`. В журнале появится `chat_id`. Добавьте свойство `TELEGRAM_CHAT_ID` с этим числом (у групп оно отрицательное).
5. «Управление развертываниями» → редактировать → «Новая версия».

Адрес скрипта скрыть нельзя: его видно в `config.js` и во вкладке «Сеть» браузера. Поэтому скрипт защищает чат менеджера сам:

- проверяет заявку: имя и телефон обязательны, от 1 до 50 позиций, тираж — целое число, срочность из списка;
- обрезает длинные поля, сообщение не длиннее 4000 символов;
- скрытое поле `website` — ловушка для ботов: такие заявки получают ответ «ок», но не отправляются;
- принимает не больше 20 заявок за 10 минут на всех.

Цены в заявке рассчитаны в браузере, и их можно подделать. Поэтому сообщение заканчивается фразой «Цены рассчитаны на сайте — проверьте перед счётом». Если спама станет много, следующий шаг — капча Cloudflare Turnstile.

При ошибке окно не закрывается, данные формы сохраняются, и под полями видна причина. Если `apiUrl` пуст, форма работает в демо-режиме и ничего не отправляет.

Страница выполняет запрос:

```text
GET <apiUrl>?action=catalog
```

Apps Script должен только прочитать таблицу и сформировать JSON. Расчёты и запись в Google Sheets ему не нужны. Полный формат ответа описан в [API_CONTRACT.md](API_CONTRACT.md).

Если URL пуст, работают демо-данные. Если URL задан, демо-данные не показываются. При любой ошибке — сеть, тайм-аут, ответ не JSON, ошибка в таблице — над калькулятором появляется красное предупреждение с причиной. Если каталог ещё ни разу не загрузился, расчёт недоступен. Если ошибка случилась при «Обновить», остаются последние загруженные данные.

Apps Script только читает листы. Проверяет данные фронтенд, и ошибка называет место словами таблицы: «Лист «Категории», категория 7: «Стоимость» — нужно число больше нуля». Над строками заголовков нельзя вставлять строки: скрипт отсчитывает их по номеру.

## Реализовано

- динамический выбор компании из каталога;
- поиск по артикулу и наименованию, «е» и «ё» не различаются;
- подсказка, если совпадений больше шести;
- связь артикула с производственной категорией;
- три зоны тиража (пример — категория 27: минимум 4 200, сниженный тираж 1 400–4 199 по 1,62 ₽):
  - меньше «Сниженное кол-во от» (1 400) — не принимаем, позицию нельзя добавить;
  - сниженный тираж (1 400–4 199) — цена сниженного тиража, только стандартный срок, кратность — шаг «от» (1 400, 2 800); показываем стоимость при минимальном тираже;
  - от минимума (4 200) — цена по срочности, кратность категории;
  - если у категории нет сниженного тиража, принимаем только от минимума;
- предложение ближайшего допустимого количества, кнопки «−» и «+» идут по допустимым значениям;
- стандартная, срочная и экстренная цена, округлённая до копеек;
- заявка из нескольких позиций;
- подсказка о доставке: бесплатная от 100 000 ₽ (порог задан в `app.js`, константа `freeDeliveryFrom`), иначе — сколько не хватает;
- выгрузка заявки в `.xlsx` через SheetJS: срочность, статус тиража, строка «Итого» с формулой `SUM`, денежный формат ячеек;
- адаптивный интерфейс и клавиатурная навигация;
- валидация и нормализация ответа API;
- безопасный вывод текстов из каталога без вставки HTML.

Форма менеджера отправляет заявку в Telegram через Apps Script. Свой бэкенд для этого не нужен.

## Проверка исходных данных

Аудит таблицы 3 ноября 2026 года:

- на листе `Категории` 39 категорий (1–39), артикулы используют 21 из них;
- листы `Список_артикулов_ГлобалФуд` и `Список_артикулов_СтудияВкуса` полностью совпадают: по 112 строк, одинаковые категории, артикулы и названия. Лист Студии Вкуса нужно заполнить её собственными артикулами;
- в обоих листах колонка `Площадка` везде равна `ГФ`. Компания определяется листом, поэтому на расчёт это не влияет;
- колонка `Стоимость` в листах артикулов в 70 строках из 112 расходится с ценой категории (например, 10165: 1,15 ₽ в листе и 1,20 ₽ в категории 27). Калькулятор берёт цену из листа `Категории`;
- в 14 строках листов артикулов цветность расходится с категорией: 11 артикулов категории 25 записаны как «Ч/Б», хотя категория 25 «Цветная»; ещё расходятся 15961, 16561 и 19455. Калькулятор показывает цветность категории;
- срочная цена (`=D×1,5`) и цена сниженного тиража (`=D×1,35`) часто дают доли копейки. Таблица показывает 1,13 ₽, а в ячейке хранится 1,125. API передаёт значение ячейки, а калькулятор округляет цену до копеек, как в таблице. Все 156 цен после округления совпадают с тем, что показывает таблица.
